# TIDEBOUND — Fischer's Fritz v1

Standalone mobile/browser prototype built from the Fisher's Fritz 0.1 direction and expanded into the Tidebound world.

## Core loop
Fish → timing battle → sell to Fritz → buy gear → rebuild harbor → unlock boat → manage fuel/range → upgrade hull/engine → build sonar → unlock submersible → descend through Abyss floors.

## Main cast
- Kai — player / wanderer
- Fritz — Harbor Master and catch buyer; warm, cryptic, protective
- Luna — Tackle Maker; confident, practical, inventive
- Nico — Shipwright; energetic, fearless, mechanically gifted
- Maris — Explorer/researcher; brilliant, curious, obsessed with the unknown
- Biscuit — Fritz's First Mate; loyal, excitable, lucky
- Skipper — Harbor Watch; grumpy, territorial, secretly helpful

## Included systems
- touch joystick + action buttons
- named NPC interactions and relationship values
- fishing tension/distance minigame
- timing-based creature combat
- 60+ buyable/unlockable items
- 28 catch species across harbor, sea and abyss zones
- shops, buyer, shipyard and research log
- boat key, hull/engine progression, fuel, sonar, submersible and Abyss floors
- XP/levels, HP/focus and local save
- responsive mobile UI and minimap

Open `index.html` in a modern browser. For iPhone testing, serving via GitHub Pages or any static host is recommended.
